# Cobalt Telegram Downloader

ربات تلگرام Node.js با Telegraf که به نمونهٔ Cobalt خودتان وصل می‌شود.

## امکانات
- دریافت لینک و انتخاب ویدیو یا موسیقی
- انتخاب کیفیت ویدیو: 1080p / 720p / 480p / 360p / 240p
- ارسال فایل در تلگرام، با لینک مستقیم به‌عنوان fallback برای فایل‌های بزرگ
- پشتیبانی پایه از پاسخ‌های `tunnel`، `redirect` و `picker` در Cobalt
- دستورهای `/start`، `/help` و `/status`
- محدودسازی اختیاری ربات به شناسه‌های عددی تلگرام

## اجرا در Railway

1. در تلگرام به `@BotFather` برو و با `/newbot` یک ربات بساز.
2. این پوشه را در GitHub قرار بده و در Railway از آن یک سرویس جدید بساز.
3. در Variables این مقادیر را تنظیم کن:
   - `BOT_TOKEN`: توکن BotFather
   - `COBALT_URL`: آدرس عمومی Cobalt، بدون اسلش انتهایی
   - `COBALT_AUTH`: فقط اگر Cobalt احراز هویت می‌خواهد؛ مثلاً `Api-Key YOUR_KEY`
   - `ALLOWED_USERS`: اختیاری؛ شناسه‌های عددی کاربران مجاز، جداشده با کاما
4. Start Command را `npm start` بگذار. Railway با `npm install` وابستگی‌ها را نصب می‌کند.

این پروژه از long polling استفاده می‌کند؛ برای آن webhook یا دامنهٔ جداگانه لازم نیست. ربات را فقط در یک replica اجرا کنید.

## اجرای محلی در Termux / Linux

```bash
pkg install nodejs-lts
npm install
cp .env.example .env
nano .env
npm start
```

## محدودیت حجم

نسخهٔ ابری Telegram Bot API در مستندات فعلی محدودیت‌هایی برای دریافت/ارسال فایل دارد. این پروژه برای آپلود مستقیم سقف پیش‌فرض 48 MiB گذاشته است؛ فایل بزرگ‌تر به‌صورت لینک Cobalt برگردانده می‌شود. برای فایل‌های بزرگ‌تر باید Local Bot API Server یا روش میزبانی/ارسال دیگری راه‌اندازی شود.

## ایموجی پریمیوم

پریمیوم بودن حساب سازنده به‌تنهایی باعث نمی‌شود ربات بتواند هر ایموجی پریمیوم را خودکار استفاده کند. برای custom emoji باید شناسهٔ دقیق `custom_emoji_id` و entity مناسب Telegram Bot API به پیام اضافه شود. این نسخه از ایموجی‌های استاندارد استفاده می‌کند تا روی همهٔ کلاینت‌ها درست نمایش داده شود.

## نکات
- آدرس Cobalt را با آدرس همان سرویس Railway خودتان جایگزین کنید.
- از ربات برای محتوایی استفاده کنید که اجازهٔ دانلود آن را دارید.
- لینک‌های Tunnel امضاشده و موقت‌اند؛ آن‌ها را عمومی نکنید.
- `local-processing` در این نسخه پشتیبانی نشده و نیازمند پیاده‌سازی FFmpeg است.
